A collection of small projects I built while learning and practicing
JavaScript fundamentals, DOM manipulation, and event handling.

## Projects

A simple calculator built with HTML, CSS, and JavaScript.

An interactive Rock Paper Scissors game featuring game logic,
score tracking, and user interaction.

### 📝 Todo List
A simple task manager for adding and removing todo items.

## Technologies

- HTML

- JavaScript

These projects were completed while working through the
